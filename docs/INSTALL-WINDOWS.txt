ЯНДЕКС УМНЫЙ ДОМ [n-bord] — WINDOWS v1.1.0
================================================

Неофициальный плагин Яндекс Умного дома для совместимых устройств Stream Dock.

Автор: nbord
GitHub: https://github.com/n-bord/yandex-smart-home-stream-dock


СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
- Windows 10 или Windows 11.
- Stream Dock 3.10 или новее.
- Доступ в интернет к API Яндекса и GitHub.
- Отдельная установка Node.js не требуется: используется среда Stream Dock.


УСТАНОВКА
---------
1. Полностью распакуйте ZIP-архив в обычную папку.
2. Запустите двойным кликом:

   INSTALL-WINDOWS.bat

3. Дождитесь сообщения об успешной установке.
4. Если Stream Dock не запустился автоматически — запустите его вручную.
5. Если плагин не появился сразу, полностью закройте Stream Dock и откройте его снова.

ВАЖНО:
- Для установки используйте только INSTALL-WINDOWS.bat.
- Файл installer\_install.ps1 является внутренней частью установщика.
  Запускать его вручную не требуется.
- Если Windows SmartScreen покажет предупреждение, разрешайте запуск только в том
  случае, если архив скачан из официального GitHub Releases проекта.


ПЕРВОЕ ПОДКЛЮЧЕНИЕ
------------------
1. Откройте панель плагина.
2. Перейдите:

   Настройки -> Подключение

3. Нажмите:

   Войти через Яндекс

4. В браузере подтвердите доступ к Яндекс Умному дому.
5. После подтверждения вернитесь в Stream Dock — подключение завершится автоматически.

Используется Authorization Code + PKCE.
client_secret в публичный плагин не встраивается.

OAuth callback работает только через локальный адрес:

http://127.0.0.1:49407/oauth/yandex/callback

Если известен срок действия токена, плагин показывает дату его окончания.
При истечении или отзыве доступа достаточно повторно нажать «Войти через Яндекс».

Ручной OAuth-токен также можно использовать как альтернативный способ подключения.

ПАНЕЛЬ УМНОГО ДОМА
------------------
На Windows панель открывается в отдельном app-окне Microsoft Edge, если Edge доступен.

Если Edge не найден, используется браузер Windows по умолчанию.

Повторное нажатие на кнопку панели должно активировать уже открытое окно вместо
создания новой копии.


ЛОКАЛЬНЫЕ ДАННЫЕ
----------------
Настройки, история и статистика хранятся в:

%APPDATA%\n-bord\Yandex Smart Home Stream Dock\

Полный сброс из настроек плагина очищает локальные данные и авторизацию.


ЖУРНАЛЫ И ДИАГНОСТИКА
---------------------
Если проблема возникла во время установки, рядом с установщиком создаётся:

install-windows.log

Для проблем после запуска используйте раздел:

Настройки -> Диагностика

Перед публикацией логов проверьте, что в них нет личной информации.
OAuth-токены и основные OAuth-параметры плагин старается маскировать автоматически.


РУЧНАЯ УСТАНОВКА
----------------
Если автоматический установщик не подходит, можно вручную скопировать папку:

com.nbord.yandexsmarthome.streamdock.sdPlugin

в каталог плагинов вашей версии Stream Dock.

Наиболее распространённые варианты:

%APPDATA%\HotSpot\StreamDock\plugins\

или

%APPDATA%\HotSpot\Stream Dock AJAZZ\installedPlugins\

После копирования полностью перезапустите Stream Dock.


УДАЛЕНИЕ
--------
Удалите папку:

com.nbord.yandexsmarthome.streamdock.sdPlugin

из каталога плагинов Stream Dock и перезапустите Stream Dock.

Локальные данные можно дополнительно удалить из:

%APPDATA%\n-bord\Yandex Smart Home Stream Dock\


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
Перед созданием Issue:

1. Перезапустите Stream Dock.
2. Проверьте подключение к Яндексу в разделе «Настройки -> Подключение».
3. Нажмите «Войти через Яндекс» повторно, если требуется авторизация.
4. Проверьте «Настройки -> Диагностика».
5. Если проблема связана с установкой — приложите install-windows.log.
6. Укажите версию Windows, Stream Dock и модель устройства.
