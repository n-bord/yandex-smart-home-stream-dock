ВАЖНО: ПЕРВЫЙ ЗАПУСК НА macOS
------------------------------
Установщик не подписан сертификатом Apple Developer и не нотарифицирован Apple.
Поэтому macOS Gatekeeper при первом запуске может показать сообщение:

«Apple не удалось подтвердить, что файл INSTALL-MAC.command не содержит вредоносного ПО…»

Это ожидаемо для текущей open-source сборки.

Если архив скачан из официального GitHub Releases проекта, разрешить запуск можно так:

СПОСОБ 1 — через настройки macOS
1. Попробуйте один раз запустить INSTALL-MAC.command.
2. Откройте:
   Системные настройки -> Конфиденциальность и безопасность.
3. Прокрутите вниз до раздела «Безопасность».
4. Рядом с сообщением о заблокированном INSTALL-MAC.command нажмите:
   «Всё равно открыть» / «Open Anyway».
5. Подтвердите запуск паролем или Touch ID, если macOS попросит.

СПОСОБ 2 — через Finder
1. Найдите INSTALL-MAC.command в Finder.
2. Нажмите по нему правой кнопкой мыши или Control + клик.
3. Выберите «Открыть».
4. В появившемся окне ещё раз нажмите «Открыть», если такая кнопка доступна.

Не отключайте Gatekeeper полностью и не выполняйте команды вроде:
  sudo spctl --master-disable

Для запуска этого установщика это не требуется.

ЯНДЕКС УМНЫЙ ДОМ [n-bord] — macOS v1.1.0
==========================================

Неофициальный плагин Яндекс Умного дома для совместимых устройств Stream Dock.

Автор: nbord
GitHub: https://github.com/n-bord/yandex-smart-home-stream-dock


БЫСТРАЯ УСТАНОВКА
-----------------
1. Полностью распакуйте ZIP-архив.
2. Дважды нажмите INSTALL-MAC.command.
3. Дождитесь сообщения «Плагин успешно установлен».
4. Если Stream Dock не запустился автоматически — запустите его вручную.
5. Откройте Настройки -> Подключение -> «Войти через Яндекс».

Установщик не требует sudo и устанавливает плагин только для текущего пользователя.
Настройки, OAuth и локальная история при обычном обновлении плагина не удаляются.

Если macOS не разрешает открыть INSTALL-MAC.command из-за настроек безопасности,
используйте правый клик -> «Открыть». Запускайте установщик только из архива,
скачанного из официального GitHub Releases проекта.


КУДА УСТАНАВЛИВАЕТСЯ ПЛАГИН
----------------------------
Основной каталог Stream Dock на macOS:

~/Library/Application Support/HotSpot/StreamDock/plugins/

Установщик также проверяет другие известные каталоги Stream Dock и, если старая
версия плагина уже установлена, обновляет её в том же месте.


ЖУРНАЛ УСТАНОВКИ
----------------
Если возникнет ошибка, окно Terminal останется открытым, а рядом с установщиком
будет создан файл:

install-mac.log

Его можно приложить к GitHub Issue для диагностики.


РУЧНАЯ УСТАНОВКА
----------------
Если автоматический установщик не подходит, скопируйте папку:

com.nbord.yandexsmarthome.streamdock.sdPlugin

в:

~/Library/Application Support/HotSpot/StreamDock/plugins/

После этого полностью перезапустите Stream Dock.


ПОДКЛЮЧЕНИЕ К ЯНДЕКСУ
---------------------
Откройте:

Настройки -> Подключение -> Войти через Яндекс

Используется Authorization Code + PKCE. client_secret в публичный плагин не
встраивается. Ручной OAuth-токен сохранён как альтернативный вариант.
