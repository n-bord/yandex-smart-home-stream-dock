# Changelog

## 1.1.0 — 2026-10-01

### Главное

- Добавлена поддержка Windows 10/11 с функциональностью, соответствующей macOS-сборке.
- Добавлена встроенная авторизация через Яндекс OAuth в браузере.
- Добавлены установщики для macOS и Windows.
- Добавлена проверка обновлений через GitHub Releases.

### OAuth

- Authorization Code + PKCE без `client_secret` в публичном плагине.
- Автоматическое сохранение OAuth-токена после входа.
- Отображение известной даты окончания токена.
- Повторная авторизация при истёкшем или отозванном доступе.
- Одноразовая OAuth-сессия с ограниченным временем жизни.
- Очистка временных `state` / `code_verifier`.
- Маскирование OAuth-токенов и чувствительных параметров в диагностике.
- Ручной OAuth-токен оставлен как альтернативный способ подключения.
- Refresh-token в публичном релизе намеренно не сохраняется.

### Windows

- Добавлена отдельная Windows-сборка.
- Установщик `INSTALL-WINDOWS.bat`.
- Исправлено отображение выпадающих списков Property Inspector.
- Исправлено открытие браузера для OAuth.
- Исправлено открытие GitHub / Releases и других внешних ссылок.
- Исправлен откат значения ползунка яркости во время применения команды.
- Добавлена защита от открытия нескольких окон панели при быстрых повторных нажатиях.
- Улучшена обработка временных сетевых ошибок и добавлен резервный сетевой путь.
- Добавлено локальное хранение данных в `%APPDATA%\n-bord\Yandex Smart Home Stream Dock\`.
- Добавлен `install-windows.log`.

### macOS

- Добавлен установщик `INSTALL-MAC.command`.
- Добавлен `install-mac.log`.
- Добавлена инструкция для первого запуска через macOS Gatekeeper.
- Установщик работает без `sudo` и обновляет плагин для текущего пользователя.

### Панель и обновления

- Добавлена проверка актуальной версии через GitHub Releases.
- Добавлены ссылки на проект и Releases.
- Улучшено поведение панели при повторном открытии.
- Сохранены отдельные интервалы обновления dashboard и действий Stream Dock.

### Документация

- README обновлён для macOS и Windows.
- Добавлены инструкции по установке, OAuth, Gatekeeper/SmartScreen и диагностике.
- Добавлен скриншот успешного подключения через Яндекс.
- Обновлены скриншоты «Настройки», «О плагине» и страницы авторизации.
- Добавлена лицензия MIT.
