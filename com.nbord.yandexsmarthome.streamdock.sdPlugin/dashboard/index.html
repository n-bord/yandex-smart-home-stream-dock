Стартовая вкладка

Раздел, который будет открываться первым при запуске панели.

Как это работает: «Обновление панели» относится только к открытому dashboard. «Обновление кнопок и ручек» управляет фоновым обновлением действий на подключённых устройствах Stream Dock. История датчиков сохраняется независимо.

Полный сброс плагина

Удаляет OAuth-авторизацию, локальную историю показателей, статистику, кэш, порядок комнат и карточек, избранное, скрытые устройства и настройки действий для клавиш и крутилок.

Сами элементы на раскладке Stream Dock могут остаться на своих местах, но их привязки и параметры будут очищены при следующем появлении.

Подключение

Один OAuth-токен используется всеми действиями плагина.

Не проверено

Аккаунт Яндекса

Требуются доступы iot:view и iot:control. Токен хранится в глобальных настройках плагина. Можно вставить сам токен или полный URL результата OAuth — в этом случае плагин также сохранит срок действия из expires_in.

Как получить токен

  1. Откройте Яндекс OAuth и создайте приложение типа «Для доступа к API или отладки».
  2. Добавьте разрешения умного дома iot:view и iot:control.
  3. Для приложения доступа к API используйте redirect URI https://oauth.yandex.ru/verification_code.
  4. Получите OAuth-токен и вставьте его выше. После проверки он станет общим для всех кнопок и крутилок.
