Сценарий
На клавише запускается выбранный сценарий. На крутилке вращение выбирает сценарий, нажатие запускает его. Избранные берутся из раздела «Избранное» панели.
Для ИК-устройств без обратной связи лучше выбрать явную команду «Включить» или «Выключить».
С ускорением: медленно — выбранный шаг, быстро — до 10% за щелчок.

Показание обновляется автоматически.
Выберите показатели для карточки. На клавише показываются до трёх значений на странице, на информационной доске — первые три выбранных, на крутилке они листаются вращением.

Стиль применяется к клавише, крутилке и информационной доске. На крутилке: вращение — переключить показатель, нажатие — обновить.
Включите реверс, если 60% в Яндексе физически выглядит как 40% открытия.
Вращение переключает режимы work_speed, нажатие включает/выключает пылесос.
Для очистителя/вентилятора автоматически доступны скорость, режим вентиляции и другие mode-capabilities устройства. Нажатие крутилки — питание.
Вращение: перелистывает палитру и сразу меняет цвет лампы. Нажатие: включает/выключает свет. Текущий цвет и его название отображаются на экране крутилки.
Создайте несколько кнопок этого действия — например отдельную белую и отдельную красную.
Если выбран цвет, он применяется вместо температуры белого света.
Для ИК-пульта текущее значение громкости неизвестно: крутилка отправляет только относительные команды «громче/тише». По умолчанию используется шаг 1.
В этом действии показываются только устройства, похожие на виртуальные ИК/медиа-устройства Яндекс Пульта. Очистители, розетки, чайники и другие обычные устройства сюда не добавляются.
На клавише действие открывает полноценную панель. На информационной доске или дополнительном экране Stream Dock отображается выбранный живой шаблон. Для отдельного датчика можно использовать действия «Датчик — Показание» или «Датчик — Показатели».
