# Яндекс Умный дом [n-bord] — Stream Dock plugin

Исходники плагина для **macOS и Windows**.

Пользовательская документация, установка, скриншоты и актуальные релизы находятся в корневом [`README.md`](../README.md) репозитория.

- Версия: `1.1.0`
- Автор: `nbord`
- OAuth: Authorization Code + PKCE
- Платформы: macOS / Windows

> Неофициальный любительский проект. Не связан с компанией Яндекс и сервисом «Умный дом» от Яндекса и не поддерживается ими.
